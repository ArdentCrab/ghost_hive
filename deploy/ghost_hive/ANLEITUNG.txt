Ghost:Hive — Live v2 (SPEC-v2)
================================

Kopfzeile Watch: ghost:hive   Titel: [GHv2] PAGE:… STATE:Watch|Down

ONE-CLICK (Stick eingesteckt)
---------------------------
Windows:  hive_live.cmd
WSL:      ./hive_live.sh
Oder:     python ghost_v2_final.py live

Live-Day (IBSS Hardware): docs/LIVE_DAY.md

Erstes Mal (PSP)
----------------
1. python ghost_v2_final.py whitelist   (PSP per USB)
2. PSP: FastRecovery -> GHOST ingest
3. python fetch_bind.py                 (peer.bind 112 B)
4. make live                            (WSL: kompletter Stick-Ordner)

Build (WSL)
-----------
make live          # peers + EBOOT + bin/ + Scripts -> deploy/ghost_hive/
                   # Kopiere deploy/ghost_hive/ nach E:\ghost_hive\

make test          # Regression
make redteam       # 2001 Peer-Angriffe

Komponenten
-----------
hive_gate.py       Stick-Gate (Worker+Relay sync + R3 wake/bind)
auto_peers.py      Local WSL peers; remote via manifest
devices.manifest   Host=local|remote, arch, network ibss|relay
wake_lan.py        GHST_WAKE v2 Broadcast beim Gate
bind_serve.py      Whitelist via devices.manifest; 5 req/min/IP; 900s window
wake/ghost_wake    Termux/Linux Listener (Port 17469)
ui/hive_manager.py Live-Dashboard (Peers, Logs, Stick)
ghost.cfg          IBSS GHSTHIVE, Kernel 10.17.47.1, UDP 17471

R3 — echte Geraete (Relay-Pfad)
-------------------------------
1. make live  (bin/amd64 + optional bin/arm64)
2. Stick -> Gate startet bind_serve + wake_lan
3. Auf Handy/Pi: python wake/ghost_wake.py P bin/arm64/ghost_phone
4. Geraet holt peer.bind, startet Peer -> Relay -> PSP

Verboten auf Stick: root.key, WPA-Join, Mini-EBOOT

PSP-UI: frozen v2 (kein Kernel-Change). Latenz-Ziele bei IBSS-Hardware messen.
