# bin/

Linux-ELF-Peers für WSL (`hive_gate` kopiert nach `/tmp/`).

Bauen und hierher legen:

```bash
make ghost-hive
```

Enthält: `ghost_laptop`, `ghost_relay`, `ghost_phone`, `ghost_nas`, `ghost_router`, `ghost_family`, `ghost_mines`.

Binaries werden nicht ins Git committed (nur lokal / Stick).
